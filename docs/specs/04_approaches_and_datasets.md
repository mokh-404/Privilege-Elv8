### 2.2 What this means for Track B

1. **Leakage under a random split.** About 10 dumps per malware sample are 15 seconds apart, so sibling snapshots of the same sample land in both train and test. Benign rows were SMOTE-oversampled, so synthetic neighbours of real benign rows can land on both sides. A random 80/20 split therefore measures near-duplicate recall. This is a likely reason for the saturated scores in the literature, and it should be stated as a likely explanation, not a proven one.
2. **`Category` leaks the label.** It contains `Benign` or the malware category and family. It must be dropped from `X` before binary classification (EV-04).
3. **Benign rows cannot be grouped by family or sample.** Benign leakage on Track B cannot be removed fully. The false-positive rate on benign rows is therefore optimistic. Mitigation in `07`: cluster-based grouping of benign rows as an approximation, and a plain statement of the caveat.
4. **Track B tests model families, not our pipeline.** The features come from a different tool version (Volatility 2.6).

| (opt.) | Logistic regression | Supervised, linear | Labelled rows | Five-line sanity baseline |

Benign rows on Track A are `baseline` + `benign_drift`. On Track B they are the `Benign` class. Unsupervised arms never see an attack row or label during training.

### 4.1 PyTorch tabular MLP (exact specification)

```
Input -> Linear(128) -> BatchNorm1d -> ReLU -> Dropout(0.3)
      -> Linear(64)  -> BatchNorm1d -> ReLU -> Dropout(0.2)
      -> Linear(32)  -> ReLU
      -> Linear(1)                      (raw logit)
Loss:      BCEWithLogitsLoss(pos_weight = num_benign / num_attack)  [computed on the training split]
Optimizer: AdamW (weight decay 1e-4 to 1e-2, searched)
Stopping:  early stopping on validation PR-AUC (patience about 10 epochs); validation split is grouped like the outer split
```

### 4.2 PyTorch deep autoencoder (exact specification)

```
Input -> Linear(64) -> ReLU -> Linear(32) -> ReLU -> Linear(16)   (bottleneck)
      -> Linear(32) -> ReLU -> Linear(64) -> ReLU -> Linear(Input)
Loss:      MSE, training rows = benign only
Score:     per-row reconstruction MSE (higher = more anomalous)
Stopping:  early stopping on benign validation reconstruction loss (no attack labels used)
Scaler:    fitted on benign training rows only
```

Model selection (not training) may use development-fold PR-AUC, which uses labels; say so in the paper.

### 4.3 Expectations

Do not assume tree models win. A small labelled dataset tends to favour trees on tabular features, and Tiwari et al.'s neural network was the weakest arm on their data, but both are hypotheses for our data. The training-size curve and SHAP comparison are the evidence for the "why".
